# JurisTwin Sentinel UI v10

The v10 visual refresh aligns JurisTwin Sentinel to JurisTech's current red / black / grey identity while keeping JurisTwin as a distinct product brand.

## Design priorities

- Regular-user simplicity remains the primary UX principle: one page, one governed answer, one safe source path.
- Superadmin complexity is grouped into a dark enterprise command centre with clear workspace, governance and appendix navigation.
- JurisTech red (`#EC1C24`) is reserved for primary actions, active navigation, brand emphasis and attention states; success remains green and warnings remain amber to preserve semantic clarity.
- Cards use bright white surfaces, restrained borders and low-noise shadows to keep dense governance information readable on a projector.
- All new interface icons are inline SVGs, so no external icon package, CDN or internet connection is required.
- Existing accessibility controls remain: keyboard focus visibility, skip link, `aria-live`, reduced-motion handling, high-contrast handling and responsive layouts.
