**Do not tour the product. Resolve one incident.**

> CONNECT → EXPOSE → SIMULATE → RECOMMEND → APPROVE → PROTECT → PROVE

## 0:00–0:25 — customer contradiction

Overview:

> “One organisation. Same customer. Two answers. The Product Owner accepts bank statements, while operations still requests payslips.”

## 0:25–1:00 — trusted answer + role proof

Platform → Secure Enterprise Memory.

- **“Hardcoded?”** Switch to restructuring or notification conflict and run it end-to-end.
- **“Where is the AI?”** Open AI Model Card: real learned model + held-out metrics + zero publication authority.
- **“Can it hallucinate?”** Ask an unrelated policy question: `NEEDS_REVIEW`, no fabricated citation.
- **“Is it resilient?”** Attack Sentinel: 16/16 HARDENED.
- **“Are external inputs live?”** Run the HMAC signed webhook from a second process.
- **“Why 27?”** Show BFS sample paths.
