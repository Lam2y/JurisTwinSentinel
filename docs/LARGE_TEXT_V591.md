# JurisTwin Sentinel v5.9.1 — Large Text / Presentation Readability

This release is a readability pass over the complete manager-facing UI.

- Small 7–16 px text has been raised to a presentation-safe 11–19 px range.
- Sidebar navigation, top bar, buttons, chips and input controls have more room for the larger type.
- Conflict Map nodes are wider and taller so larger labels remain readable without truncation.
- Manager-facing explanations, source controls, audit logs, evidence cards and governance checks are easier to read on a laptop or projector.
- Responsive fallbacks preserve usability on narrower displays.
- Static asset version is bumped to v5.9.1 to prevent stale browser CSS from being reused.

No security, governance, conflict-resolution or backend decision logic was weakened by this visual change.
