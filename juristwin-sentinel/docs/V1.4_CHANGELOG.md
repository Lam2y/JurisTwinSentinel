# JurisTwin Sentinel v1.4 — Grand Finals Visibility & Motion Upgrade

## Readability
- Increased the prototype typography scale while preserving the original 1440×1024 geometry.
- Brighter secondary text and stronger borders for projectors and large displays.
- Heavier small text, higher contrast modal/toast styling, and improved anti-aliasing.

## Interaction & motion
- Screen entrance transitions and staggered card reveals.
- Hover lift/glow and click feedback on interactive controls.
- Animated primary-action shimmer.
- Live status pulse, alert breathing, KPI count-up animation.
- Evidence-network node float and connector pulse.
- Keyboard-accessible clickable controls (Enter/Space).

## Presentation controls
A small floating control appears at the right edge:
- `C` = high-contrast projector mode.
- `F` = focus mode using more horizontal screen space.
- `M` = pause/resume motion.

Keyboard shortcuts use the same keys when focus is not inside an input.

## Finals recommendation
Use standard fit mode on 4:3 displays. On a 16:9 projector, enable `C` first; use `F` if you need larger text and are comfortable with slight vertical scrolling.
