# JurisTwin Sentinel v1.5 — Interaction Guide

## Evidence Network Graph
- Drag any evidence node anywhere inside the graph canvas.
- Connectors follow the nodes in real time.
- Click any node to inspect its evidence context.
- Click **Reset layout** or double-click empty graph space to restore the original layout.

## Global interactions
- Click **All systems operational** for a live backend/database/ledger health check.
- Click **Michelle Tan** for the authenticated identity/RBAC view.
- Click the JurisTwin brand to return to Command Center.
- Press `Ctrl/Cmd + K` to open governed search.
- Presentation controls remain: `C` contrast, `F` focus, `M` motion.

## Command Center
KPI cards, priority conflicts, integrity score, and recent audit events are interactive.

## Case Workspace
Customer profile, documents, timeline events, and evidence items open contextual details.

## Decision Digital Twin
Options A/B/C can be selected and compared. Option C remains the governed publishable scenario.

## Approval
Implementation steps, affected assets, authorization roles, comments, Reject, Request Changes, and Publish are interactive.

## Decision Ledger
Decision record, registry ID, version history, audit events, version comparison, export, and integrity verification are interactive.

## AI Bodyguard
KPI cards, version comparison, incident explanation/activity, revoke, escalate, restore, and authorised override controls are interactive.

## Secure Enterprise Memory
Search, filter pills, source cards, access badges, and Manager/Officer/Intern role previews are interactive.

## Integrations & Administration
Connected adapters can be synchronized. Gmail opens configuration guidance. RBAC role rows show permission context. Security shield rows can be toggled in the local UI preview without changing production policy.
