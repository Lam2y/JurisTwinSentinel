# v1.6 Interaction Guide

## Canvas
- `+` / `-`: zoom
- `0`: fit screen
- Ctrl + mouse wheel: zoom
- `C`: projector contrast
- `F`: focus mode
- `M`: pause/resume animation
- `Ctrl + K`: global search
- `Ctrl + Shift + R`: reset finalist scenario

## Conflict graph
Drag any evidence node. Ten labelled SVG relationships follow the node positions live. Click a node to inspect its evidence.

## Decision Twin
Click **Adjust Weights**, move the three sliders and press **Recalculate Twin**. The request goes to FastAPI and creates a new Simulation. The screen redraws from the returned metrics.

## Enterprise Memory
Click filter chips repeatedly to cycle values. Results are re-queried from the backend. Click Manager / Officer / Intern to preview their backend evidence access level.

## Decision Ledger
The screen is generated from the latest backend DecisionContract, DecisionVersion and LedgerEntry state. Bodyguard changes appear when the page is refreshed/opened.

## Bodyguard
- Review Activity: updates status + timeline + ledger.
- Request Explanation: runs backend explanation and records the review request.
- Revoke Access: disables QA-014.
- Escalate: persists escalation status.
- Authorised Overwrite: changes JT-084, creates a new version and raises affected customer risk.
- Restore: restores the governed bank-statement rule as another version and clears affected-case risk.

## Integrations
Click any connector. Connected connectors offer **Sync Now** and **Pause**. Inactive Gmail offers **Connect**. Counts, errors, timestamps and status refresh from the backend.

## Administration
Click any RBAC role to edit its actual capability policy. Click any Security Shield row to persistently enable/disable the corresponding finalist backend control.
