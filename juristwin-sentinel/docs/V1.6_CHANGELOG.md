# JurisTwin Sentinel v1.6 — Live Product Build

## What changed

### Full-canvas interaction
- Zoom in/out controls, fit-to-screen, fullscreen, keyboard +/-/0 and Ctrl+mouse-wheel zoom.
- Existing high-contrast, focus and motion controls retained.

### Conflict Intelligence
- Replaced prototype connector shapes with a real SVG network.
- 6 draggable evidence nodes and 10 curved, labelled relationships.
- Edges recompute live while a node is dragged.
- Removed the malformed green rotated rectangle from the old prototype.

### Decision Digital Twin
- Weight changes are sent to FastAPI and stored as a new Simulation record.
- Weights alter operational assumptions, projected delay, complaint risk, policy alignment, duplicate requests, affected applications and weighted decision fit.
- The option cards and comparison values redraw from the returned simulation.
- RBAC `can_modify_twin` capability is enforced by the backend.

### Secure Enterprise Memory
- Search filters are executed server-side: source, customer, project, tier, authority, sensitivity, status, version and date range.
- Filter clicks cycle through real values and immediately redraw the evidence result panel.
- Manager can preview Manager / Officer / Intern memory access behavior.
- Data Sensitivity Masking affects redaction.
- DLP download checks are recorded in the ledger.

### Decision Ledger
- Live ledger page now reads the current DecisionContract, DecisionVersion history and decision-linked LedgerEntry rows.
- Version history updates after approval, authorised overwrite and restore.
- Refresh, SHA-256 verification and CSV export are live backend actions.
- 7-Year Ledger Retention state is displayed from SecurityShield configuration.

### AI Bodyguard
All five controls perform real demo-state actions and append governance records:
- Review Activity → marks incident reviewed and appends timeline/ledger event.
- Request Explanation → returns a backend white-box explanation and records the request.
- Revoke Access → disables the seeded QA-014 user account.
- Escalate to Compliance → changes incident status and appends escalation event.
- Mark as Authorised Overwrite → creates a new decision version and re-evaluates the 27 affected cases.
- Restore Approved Version → creates another decision version and re-aligns affected cases.

### Enterprise Core Integrations
The live management panel exposes all 10 connectors:
- Outlook Extractor
- MS Teams Listener
- Gmail Connector
- SharePoint Indexer
- OneDrive Loader
- ClickUp Workspace
- Customer Core API
- QA Repository
- PostgreSQL DB
- ChromaDB vector

Connected integrations support live sync. Inactive connectors can be connected. Connected connectors can be paused. Every state change is persisted and written to the governance ledger.

### RBAC + Security Shields
Role policies are persisted in `role_policies` and can change:
- enabled state
- maximum sensitivity
- Digital Twin modification permission
- governed override permission
- ledger export permission
- Bodyguard review permission

Security shields are persisted in `security_shields`:
- Data Sensitivity Masking
- Active DLP Protection
- 7-Year Ledger Retention
- OOH Modification Guard

These are no longer local visual toggles.

## Automated validation
- Existing E2E tests retained.
- New v1.6 tests cover Digital Twin recalculation, Memory filtering, integration connect/sync/pause, shield updates, RBAC enforcement, Bodyguard actions, decision-version changes and ledger integrity.
